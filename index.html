Responsável Prazo

Como usar. Clique em qualquer texto e edite. Os botões no pé de cada cartão movem a atividade entre as colunas. + subtarefa abre um item com caixa de marcar. As caixas do topo filtram por frente — clique de novo para desmarcar.

Como salvar para a equipe. O que você edita fica no seu navegador na hora. Clique em Publicar para gravar no dados.json do repositório: o painel copia os dados e abre o arquivo no GitHub para você colar e confirmar. Ninguém precisa de token nem senha.

Publicar para a equipe

Os dados já foram copiados. No GitHub que vai abrir, selecione tudo, cole por cima e confirme.

Importar dados

Cole um dados.json salvo antes. Isso substitui o que está na tela.
